# lang/strings.txt - Jotter's interface words, in English, German, French, Spanish and Italian.
# kit/shared/tools/mklang.py makes amiga/lang_table.h from this file and the kit's own
# (kit/shared/lang/kit-strings.txt); kit/shared/tools/langcheck.py checks the source against both.
# One row per English string, five columns split by a TAB: the English exactly as the C source has
# it, then German, French, Spanish, Italian. UTF-8, but only Latin-1 letters. "-" is "as English".
# The terms are Microsoft Word's and Notepad's in each language (Datei/Fichier/Archivo/File,
# Zwischenablage/Presse-papiers/Portapapeles/Appunti...). German runs about a third longer than
# English: keep ribbon labels short (kit/amiga/tools/ribbonfit.py checks they fit 640 pixels).
#
# Adding a string: write it in English in the source inside tr() (or where it is translated when
# shown: menus, ribbon labels, the command table), run langcheck.py --rows, paste its row here
# under the right section, translate the four columns, run mklang.py.
